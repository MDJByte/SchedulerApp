# SchedulerApp
Built a C# Scheduler Application that enables users to create, organize, and manage appointments through a centralized scheduling system. The application helps users keep track of upcoming events, maintain structured schedules, and improve time management. Features include appointment creation, modification, and deletion, with an emphasis on usability, efficient navigation, and reliable data handling. Through this project, I gained hands-on experience developing desktop applications, working with structured data, and creating software that solves everyday organizational challenges.
